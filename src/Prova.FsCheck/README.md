# Prova.FsCheck

Property-based testing for [Prova](https://github.com/Digvijay/Prova), built on [FsCheck](https://fscheck.github.io/FsCheck/) 3.

## Install

```xml
<PackageReference Include="Prova.FsCheck" Version="0.6.0" />
```

## Usage

Mark a method with `[Property]`. Each parameter is generated by FsCheck; the test passes when the body holds for every generated case.

```csharp
using Prova;

public class ListProperties
{
    [Property]
    public bool Reverse_Twice_Is_Identity(int[] xs)
        => xs.Reverse().Reverse().SequenceEqual(xs);
}
```

## Configuration

`[Property]` forwards its settings to the FsCheck runner:

| Property | Meaning | Default |
| --- | --- | --- |
| `MaxTest` | Number of cases to generate | 100 |
| `MaxFail` | Maximum rejected cases before giving up | 1000 |
| `StartSize` | Initial generator size | 1 |
| `EndSize` | Final generator size | 100 |
| `Verbose` | Print every generated case | `false` |
| `QuietOnSuccess` | Suppress the success summary | `false` |

```csharp
[Property(MaxTest = 1000, Verbose = true)]
public bool Addition_Is_Commutative(int a, int b) => a + b == b + a;
```

> Releases before 0.6.0 accepted these values but silently discarded them, so every
> property ran exactly 100 cases. See `docs/known-issues.md` entry 8b.
